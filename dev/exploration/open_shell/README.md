# 开贝壳小游戏实机勘察与自动化规格说明 (Exploration Package)

## 1. 勘察概况
- **测试环境**: MuMu 模拟器 (ADB: 127.0.0.1:16384)
- **分辨率规格**: 原始采集 1920x1080，已按 MaaFramework 标准统一缩放为 1280x720 (短边 720p)
- **实际转移路径**: A (活动初始页) -> B (开贝壳) -> C1 -> C2 -> C3 -> D (遇章鱼) -> E (太好了) -> A (闭环返回)
- **闭环结果**: 成功消耗 1 个卷轴完成完整一轮，怒气进度从 12% 升至 13%，回到活动初始页并通过模板匹配 1.0 回测。

## 3. 动画与过渡耗时特征
1. **B 点击后的开贝壳动画**:
   - 点击后约 0.15s 画面变化。
   - 动画过程中下方短暂显示“点击跳过动画”。
   - 动画完全播放完毕至稳定按钮出现耗时约 **2.8s ~ 3.5s**。
   - 建议 Pipeline 的 post_delay 设置为 500ms，并通过 `next` 轮询等待判定。
2. **C / D 判定优先级**:
   - 判定节点顺序：先识别特殊状态 `D (保留一个随机奖品)` 和 `E (太好了)`，再兜底识别 `C (继续开贝壳)`。
