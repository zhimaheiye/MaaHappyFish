### 🟡 GoldenDolphinTask（金海豚小游戏）

**状态**: 四类奖励全屏识别、可选最高优先级、同帧即时兜底与连续三局已完成代码实现和离线验证；本次未做模拟器测试。

**重大机制发现（Hidden Trigger Mechanism）**：
- **进入小游戏后不是立即开始正式计时，存在隐藏启动状态**：
  ```
  进入小游戏
      ↓
      所选优先级无命中时，同帧识别并点击实际贝币
      ↓
      奖励雨开始后继续按用户优先级逐帧收集
  ```
- **未点击时**：
  - 只掉落初始金币；
  - 不出现经验星、爱心、宝石等进阶奖励；
  - 其余类别无命中时会自然兜底到贝币，持续点击实际贝币完成激活。
- **正式状态机设计硬契约**：
  - 每帧先识别用户所选最高优先级；未命中即在同一帧检查其余类别，不设置时间门槛；
  - 爱心、4 种宝石、3 种贝币和 2 种经验星全部使用完整 `1280×720` 画面识别；
  - 默认优先经验星，也可选择爱心、宝石或贝币；首选存在时不会被其他类别抢占，首选缺失时不会空等；
  - 每局结算后等待取消按钮模板出现，点击实际命中位置，并以 `主界面特征.png` 确认返回鱼缸后才重新导航或推进队列；最多连续执行 3 局，机会用完为正常 `NO_STAMINA` 分支；
  - 所有点击都来自识别结果，不使用固定坐标兜底。

**视觉与物理适配已就绪基础**：
- **算法就绪**：Method E（HSV 粗筛 + 几何硬过滤 + 局部微补丁模板确认）已验证：准确率 92.4%，召回率 97.5%，耗时 33ms，金币负样本 0 误检；
- **物理坐标映射**：MuMu 模拟器物理为 1080p ($1920\times1080$)，截图为 720p ($1280\times720$)，ADB 点击坐标需缩放 $1.5$ 倍；
- **全链路资产**：游乐园入口、金海豚图标、确定按钮、爱心、4 种宝石、3 种贝币、2 种经验星与结束取消按钮模板均已接入；编号后缀代表同一奖励类别的不同视觉变体；
- **详细功能文档**：见 `docs/features/golden-dolphin.md`。
