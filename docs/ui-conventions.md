# 游戏通用 UI 识别约定

## 通用返回按钮

- 适用语义：用户后续提到“通用的返回按钮”时，指游戏页面左上角带“返回”文字的按钮。
- 识别方式：OCR。
- `expected`：`返回`。
- `roi`：`[1, 0, 189, 119]`（基准画面 `1280×720`）。
- 动作：点击 OCR 实际识别结果；禁止设置固定坐标 `target` 作为识别失败后的兜底。
- 验证边界：这是用户提供的通用约定，目前随驯鹿鱼功能首次接入；是否适用于具体新页面，仍应由对应功能的 MFA 实测结果确认。

## 意外活动页面退出

- 模板：`活动页面_退出.png`（用户手动提供）。
- 识别 ROI：`[0, 0, 136, 116]`。
- 用户确认语义：任意任务中识别到该模板，即表示活动页面已经弹出；点击模板实际命中位置会返回鱼缸主页面。
- 处理方式：通过 `[JumpBack]GlobalActivityPagePopup` 优先处理，返回鱼缸后继续原任务；禁止使用固定坐标兜底。
- 原子动作边界：“点击产物气泡 → 立即滑动收取”之间不插入页面检查，在紧接着的下一个 Pipeline 检查点处理。
- 验证状态：代码级资源加载与全局接入测试通过；本次未做模拟器测试。

## 大章鱼开贝壳页面返回

- 第一层入口页门禁：`开贝壳_误触识别.png`，ROI `[498,80,280,191]`，阈值 `0.8`。该层是从主鱼缸点击贝壳后、点击“进入”前的页面；收鱼/巡检命中时视为误触，在 `[1,0,189,119]` OCR 点击左上角“返回”。
- 页面门禁模板：`开贝壳_识别.png`，ROI `[37,68,226,142]`，阈值 `0.8`。
- 返回动作模板：`贝壳页面_返回.png`，ROI `[0,0,250,150]`，阈值 `0.75`。该素材只截取返回按钮，不能单独作为大章鱼页面门禁。
- 多鱼缸巡检分别通过 `[JumpBack]PatrolShellEntryMisTouchPopup` 和 `[JumpBack]PatrolShellPagePopup` 处理第一、第二层；收鱼挂机对应使用 `HandleShellEntryMisTouch` 与 `HandleShellPage`。独立开贝壳任务在第一层继续点击“进入”，只有收鱼/巡检把它视为误触返回。
- 此页面不得使用 `活动页面_退出.png` 代替识别；两种模板代表不同页面状态。

## 快报页面关闭

- 页面门禁：在 `[635,23,226,162]` OCR 识别“快报”。
- 关闭动作：门禁通过后，在 `[1044,77,26,31]` 匹配 `快报页面_关闭.png` 并点击模板实际命中位置，不设置固定 `target`。
- 全局处理：20 份标准 `1280×720` 游戏 Pipeline 的状态转换检查点优先调用 `[JumpBack]GlobalNewsPopup`，关闭后恢复刚才的节点继续执行；原子动作只在完成后的下一检查点处理。
- 验证状态：代码级资源加载与全局接入测试通过，本次未做模拟器测试。

## 主鱼缸好友入口与海牛返回

- 主鱼缸进入好友列表使用 `好友页面_入口.png`，ROI `[1128,205,131,124]`，点击模板实际命中位置；适用于好友摸宝和海牛先生独立任务。
- 海牛独立任务退出使用通用 OCR `返回`，但两次点击之间必须先 OCR 确认已经进入“星级好友”列表，第二次点击后必须用 `主界面特征.png` 确认回到主鱼缸。

## 升级弹窗关闭

- 页面门禁：在 `[200,348,378,185]` 匹配用户提供的 `升级弹窗_识别.png`。
- 关闭动作：门禁通过后，在 `[957,627,125,47]` OCR 识别“太好了”，点击 OCR 实际命中位置；不设置固定 `target`。
- 全局处理：20 份标准 `1280×720` 游戏 Pipeline 的状态转换检查点优先调用 `[JumpBack]GlobalLevelUpPopup`，关闭后恢复刚才的节点继续执行；原子动作只在完成后的下一检查点处理。
- 坐标边界：手机 `1600×720` 与模拟器 `1280×720` 两份外部广告流水线都不复用这套游戏内全局模板和 ROI，避免广告页面误触。
- 验证状态：代码级资源加载与全局接入测试通过，本次未做模拟器测试。
