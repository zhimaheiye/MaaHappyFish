# 游戏通用 UI 识别约定

## 页面身份与按钮文字

- 圆形或小图标的模板矩形可能含不响应点击的背景角，不依赖 Maa 默认矩形随机落点。已确认目标可用 `ClickRecognizedCenterAction` 点击当帧有效命中框中心；它不提供识别失败后的坐标兜底，仍需后续页面门禁确认转换。

- 绿色按钮或指定区域的绿色像素只能辅助定位，不能单独证明结算弹窗存在；动态鱼缸也可能满足颜色条件。先验证页面独有标题，再识别该页按钮，正常流程与恢复入口共用同一门禁。
- 按钮文字同时出现在弹窗说明中时，使用完整文字正则或有证据的按钮 ROI 排除说明段落；禁止把较大说明框的中心当作按钮。用户要求全屏识别时保留全屏范围，通过正则约束目标。
- 弹窗内点击后须确认转换成功再点击背景页面；仍在弹窗时有界等待并停止，不能穿透点击背景返回。2026-09-27 乐队鱼与驯鹿鱼的实例、离线识别证据见对应功能文档。

## 通用返回按钮

2026-10-09 补充：游戏的跳舞鱼提示是居中双按钮弹窗，不属于通用「返回」或活动页左上退出。共享活动检查点仅在 OCR 命中独有文案「跳舞鱼可以跳舞了」时点现场红叉中心，连续两帧提示消失且主鱼缸模板命中才恢复原任务；绿色对勾不点。证据与未做实机复测的边界见 `docs/features/daily-sign.md`。

- 适用语义：用户后续提到“通用的返回按钮”时，指游戏页面左上角带“返回”文字的按钮。
- 识别方式：OCR。
- `expected`：`返回`。
- `roi`：`[1, 0, 189, 119]`（基准画面 `1280×720`）。
- 动作：点击 OCR 实际识别结果；禁止设置固定坐标 `target` 作为识别失败后的兜底。
- 验证边界：这是用户提供的通用约定，目前随驯鹿鱼功能首次接入；是否适用于具体新页面，仍应由对应功能的 MFA 实测结果确认。

## 意外活动页面退出

- 模板：`活动页面_退出.png`（用户手动提供）。
- 识别 ROI：`[0, 0, 136, 116]`。
- 用户确认语义：任意任务中识别到该模板，即表示活动页面已经弹出；点击模板实际命中位置会返回鱼缸主页面。
- 处理方式：通过 `[JumpBack]GlobalActivityPagePopup` 优先处理，返回鱼缸后继续原任务；禁止使用固定坐标兜底。
- 2026-10-02 该节点改为兼容路由：先辨识“幸运时刻”标题，再处理原活动返回模板。幸运时刻每次点击都须标题/正文双门禁，通过现场确认的红叉中心关闭，最多三次并确认回缸；坐标仅属于该已确认弹窗，不是模板失败兜底，不外推其它活动。详见 `docs/features/daily-sign.md`。
- 日常收尾主动领取酿月食香活动体力时是明确例外：当前步骤先于全局意外活动页处理器判定，活动列表由该子任务按卡片名称门禁处理；其它步骤仍走全局处理器。
- 全局接入按具体检查点与页面内链区分，不要求在所有 `next` 前盲插关闭处理器。配置链、局内恢复、主动活动的精确节点例外及强制顺序检查见 `docs/features/daily-sign.md`；新增节点默认受全量测试检查，不能因属于同一文件而自动豁免。
- 收取链边界：多鱼缸巡检在气泡点击前同帧确认本缸与右侧安全 ROI 的金币，点击后的正、反滑动分别再确认本缸。不能以“原子动作”为由穿透到活动页扫底；失配转回该缸观察窗口的已有恢复分支，未知页安全失败。单缸旧扫底链本次未改，具体范围见 `docs/features/patrol.md`。
- 验证状态：代码级资源加载与全局接入测试通过；本次未做模拟器测试。

## 大章鱼开贝壳页面返回

- 第一层入口页门禁：`开贝壳_误触识别.png`，ROI `[498,80,280,191]`，阈值 `0.8`。该层是从主鱼缸点击贝壳后、点击“进入”前的页面；收鱼/巡检命中时视为误触，在 `[1,0,189,119]` OCR 点击左上角“返回”。
- 页面门禁模板：`开贝壳_识别.png`，ROI `[37,68,226,142]`，阈值 `0.8`。
- 返回动作模板：`贝壳页面_返回.png`，ROI `[0,0,250,150]`，阈值 `0.75`。该素材只截取返回按钮，不能单独作为大章鱼页面门禁。
- 多鱼缸巡检分别通过 `[JumpBack]PatrolShellEntryMisTouchPopup` 和 `[JumpBack]PatrolShellPagePopup` 处理第一、第二层；收鱼挂机对应使用 `HandleShellEntryMisTouch` 与 `HandleShellPage`。独立开贝壳任务在第一层继续点击“进入”，只有收鱼/巡检把它视为误触返回。
- 此页面不得使用 `活动页面_退出.png` 代替识别；两种模板代表不同页面状态。

## 快报页面关闭

- 页面门禁：在 `[635,23,226,162]` OCR 识别“快报”。
- 关闭动作：门禁通过后，在 `[1044,77,26,31]` 匹配 `快报页面_关闭.png` 并点击模板实际命中位置，不设置固定 `target`。
- 全局处理：已接入的标准 `1280×720` 游戏状态转换检查点优先调用 `[JumpBack]GlobalNewsPopup`，关闭后恢复刚才的节点继续执行；原子动作只在完成后的下一检查点处理。局部链兼容边界见 `docs/features/daily-sign.md`，不承诺任意页面中断恢复。
- 验证状态：代码级资源加载与全局接入测试通过，本次未做模拟器测试。

## 主鱼缸好友入口与海牛返回

- 主鱼缸进入好友页使用 `好友页面_入口.png`，ROI `[1128,205,131,124]`，点击模板实际命中位置；适用于好友摸宝和海牛先生独立任务。入口可能打开留言箱，不能默认已经在列表。
- 共享 `[JumpBack]FriendPageMessageBoxToStarFriends` 在 `[40,90,660,80]` OCR 确认“未读留言最多保留”，再点击第 3 页签 `[489,41,8,8]`，必须在 `[110,100,200,55]` 确认“星级好友”才返回调用方。第 2 页签是资料页，不作为快捷入口；未知页不套用此坐标。海牛的留言箱启动仍受周末门禁约束，并且不处理留言内容。
- 好友摸宝不再复用上面的直接跳转。它用 `FriendGemMessageInbox` 在同一文案门禁下按「留言箱」选项处理当前屏，再点同一第 3 页签中心并复核“星级好友”。默认不点留言按钮。离开留言箱后又不是星级好友列表时失败，不盲点。
- 海牛独立任务退出使用通用 OCR `返回`，但两次点击之间必须先 OCR 确认已经进入“星级好友”列表，第二次点击后必须用 `主界面特征.png` 确认回到主鱼缸。

## 升级弹窗关闭

- 页面门禁：在 `[200,348,378,185]` 匹配用户提供的 `升级弹窗_识别.png`。
- 关闭动作：门禁通过后，在 `[957,627,125,47]` OCR 识别“太好了”，点击 OCR 实际命中位置；不设置固定 `target`。
- 全局处理：已接入的标准 `1280×720` 游戏状态转换检查点优先调用 `[JumpBack]GlobalLevelUpPopup`，关闭后恢复刚才的节点继续执行；原子动作只在完成后的下一检查点处理。局部链兼容边界见 `docs/features/daily-sign.md`。
- 坐标边界：手机 `1600×720` 与模拟器 `1280×720` 两份外部广告流水线都不复用这套游戏内全局模板和 ROI，避免广告页面误触。
- 验证状态：代码级资源加载与全局接入测试通过，本次未做模拟器测试。
