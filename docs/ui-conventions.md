# 游戏通用 UI 识别约定

## 通用返回按钮

- 适用语义：用户后续提到“通用的返回按钮”时，指游戏页面左上角带“返回”文字的按钮。
- 识别方式：OCR。
- `expected`：`返回`。
- `roi`：`[1, 0, 189, 119]`（基准画面 `1280×720`）。
- 动作：点击 OCR 实际识别结果；禁止设置固定坐标 `target` 作为识别失败后的兜底。
- 验证边界：这是用户提供的通用约定，目前随驯鹿鱼功能首次接入；是否适用于具体新页面，仍应由对应功能的 MFA 实测结果确认。

## 意外活动页面退出

- 模板：`活动页面_退出.png`（用户手动提供）。
- 识别 ROI：`[0, 0, 136, 116]`。
- 用户确认语义：任意任务中识别到该模板，即表示活动页面已经弹出；点击模板实际命中位置会返回鱼缸主页面。
- 处理方式：通过 `[JumpBack]GlobalActivityPagePopup` 优先处理，返回鱼缸后继续原任务；禁止使用固定坐标兜底。
- 原子动作边界：“点击产物气泡 → 立即滑动收取”之间不插入页面检查，在紧接着的下一个 Pipeline 检查点处理。
- 验证状态：代码级资源加载与全局接入测试通过；本次未做模拟器测试。

## 大章鱼开贝壳页面返回

- 专用模板：`贝壳页面_返回.png`，ROI `[0,0,250,150]`，阈值 `0.75`。
- 该模板已由 `CollectFishTask/HandleShellPage` 使用；多鱼缸巡检误入时通过 `[JumpBack]PatrolShellPagePopup` 复用并点击实际模板命中位置。
- 此页面不得使用 `活动页面_退出.png` 代替识别；两种模板代表不同页面状态。
