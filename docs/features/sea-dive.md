## 启动状态与状态机

当前支持从深海主页、展开的鱼缸列表、鱼缸 3、鱼缸 1 / 2 启动。`SeaDiveStartRouter` 按这个深度顺序识别；未知页面（包括局内、深度选择、结算、挽留弹窗）安全停止。

```text
SeaDiveTask → SeaDiveStartRouter
  → (鱼缸1/2 → 展开列表 → 鱼缸3确认 | 已在鱼缸3 | 已在深海主页)
  → 潜艇实际 bbox → 深海主页标题门禁 → SeaDiveFreeStateRouter
      ├─ PAID(x12)：主页 X → 鱼缸3确认 → 列表鱼缸1 → 主鱼缸确认 → 结束
      ├─ FREE(红角标)：
      │   点击免费按钮 → 深度选择页门禁 → 100米点击
      │   → 局内返航门禁 → 点返航 → 结算页门禁 → 左侧返航
      │   → 挽留弹窗等待 → 点确定 → 回主页验证 → 回到 FreeStateRouter（循环）
      └─ UNKNOWN：StopTask（零下潜点击）
```

循环逻辑：不写死次数，每轮结束回主页后重新判断状态。当天剩 2 次跑 2 轮，剩 1 次跑 1 轮，剩 0 次/x12 直接退出。
