# 驯鹿鱼送收礼物

**最后更新**：2026-09-08  
**证据模式**：用户手动截图  
**实机状态**：尚未测试

## 功能范围

本功能仅作为 `DailyRoutineTask` 的可选子任务，默认不勾选。入口模板 `游乐园入口.png` 与 `驯鹿鱼_入口.png` 均由用户提供；本轮不使用 ADB/maa-mcp 复核图片。

```text
鱼缸
  -> 模板点击 游乐园入口.png
  -> 模板点击 驯鹿鱼_入口.png
  -> 页面状态路由
       ├─ OCR“一键收取” [672,558,245,150]
       │    -> OCR“返回” [536,437,210,150]
       │    -> 通用返回
       └─ OCR“一键回礼” [480,562,232,143]
            -> 全屏 OCR“直接赠送” -> 点击 -> 通用返回
            └─ 未出现弹窗 -> 通用返回
  -> 模板确认回到鱼缸
  -> 推进日常收尾队列
```

## 安全与兼容边界

- 所有点击均由当前页面的模板或 OCR 命中触发，不使用固定坐标兜底。
- “直接赠送”按用户要求暂不限制 ROI；仅在点击“一键回礼”之后优先识别。
- 当前不点击右侧“去送礼”，也不猜测尚未提供的弹窗或空状态。
- 如果遇到未收录页面，流程记录“请补充流程”并安全停止，不把未知状态伪装成成功。
- 通用返回按钮采用 `docs/ui-conventions.md` 中的 OCR 契约：`expected: 返回`、`roi: [1,0,189,119]`。
