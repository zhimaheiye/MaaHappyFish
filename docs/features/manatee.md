# 海牛先生周末喂食 (`ManateeTask`)

## 功能定位

海牛先生只在周六、周日出现。该流程既可通过独立 `ManateeTask` 运行，也会在 `FriendGemTask` 遍历好友时自动接管海牛先生页面；喂食完成后依据来源返回主鱼缸或继续下一位好友。

本轮采用用户手动截图模式，模板名称、页面语义和 ROI 按用户提供的数据直接接入；仅完成代码级验证，未运行模拟器。

## 支持的启动状态

独立任务采用最深阶段优先的状态路由，支持：

1. 已打开海牛先生的选择鱼食面板；
2. 已进入海牛先生页面；
3. 已在“我的星级好友”列表且海牛先生卡片可见；
4. 周末位于留言箱，识别“未读留言最多保留”后点击第 3 页签并确认星级好友列表；
5. 周末位于主鱼缸，可点击好友入口，经留言箱桥接进入列表。

如果是工作日且当前没有识别到上述海牛状态，任务会正常结束，不进入好友列表。好友摸宝仍以真实页面为准：遍历时只要实际识别到海牛先生，就会执行活动，不依赖本机日期猜测页面。

## 状态流程

```text
独立任务 / 好友摸宝遇到海牛先生
  -> 确认海牛先生页面
       -> 已识别到“0剩余”：不再投喂，直接完成
       -> 尚未耗尽：识别并点击好友喂食
  -> 识别并点击指定鱼食
  -> 每次确认仍在海牛页面后，在安全水域循环点击
       -> 每次投喂前检查“0剩余”
       -> 已为 0：无需继续投喂，直接完成
       -> 未为 0：执行一次投喂后继续循环
       -> 120 次仍未命中：安全停止
  -> 独立任务：左上角返回 -> 确认好友列表 -> 再返回 -> 确认主鱼缸
  -> 好友摸宝：点击右上角下一位 -> 恢复好友序号和气泡状态机
```

## 用户截图与识别契约

| 目标 | 方式 | ROI / 点击范围 |
| --- | --- | --- |
| 主鱼缸好友入口 | `好友页面_入口.png` | `[1128,205,131,124]` |
| 好友列表中的海牛先生 | OCR `海牛先生` | `[460,185,183,127]` |
| 海牛页面身份 | OCR `海牛先生` | `[300,40,350,80]` |
| 好友喂食按钮 | `好友_喂食.png` | `[1126,258,143,145]` |
| 指定鱼食 | `海牛先生_选择喂食.png` | `[795,265,159,135]` |
| 连续投喂区域 | 已确认海牛页面后的有界点击 | `[792,288,341,355]`；代码使用矩形内九个固定安全点轮换 |
| 体力耗尽 | OCR `^0剩余$` | `[37,88,219,149]` |
| 独立任务返回 | OCR `返回` | 通用返回 ROI `[1,0,189,119]`，每次点击后验证目标页面 |

指定鱼食是海牛页面自己的 `海牛先生_选择喂食.png`。它不是海星「选择喂食」里的廉价、普通、高级三袋，也不购买。海星三袋的规则见 `docs/game-knowledge.md`。

所有导航点击均由当前页面 OCR 或模板门禁触发。进入海牛页面后会先检查 `^0剩余$`，避免已耗尽时继续执行；投喂循环在**每次点击前**重新识别该终态，并重新确认仍在海牛页面。旧版“至少先投 30 次再允许判断耗尽”的 `min_clicks` 语义已经移除，因此任务可能在 0 次点击时就确认已耗尽。未耗尽时在九个安全点轮换点击，当前点击间隔约 0.2 秒；MFA 停止、截图失败、页面门禁丢失或达到 120 次仍无终态时立即停止，不会点击左侧付费刷新区域。

## 与好友摸宝的集成

- `FriendGemTask` 初始化时把海牛返回模式设置为 `friend_gem`；
- 好友摸宝从好友列表第一位正常开始，不提前跳到海牛，避免漏掉前序普通好友；
- 正常遍历进入海牛页面时，旧“直接跳过”分支改为进入共享喂食流程；
- 识别到 `^0剩余$` 后复用既有 `FriendGemNextFriend -> FriendGemStepIndex -> FriendGemResetAttempts -> FriendGemFriendRouter`，继续后续好友；
- `FriendGemTask` 新增主鱼缸入口，因此可从主鱼缸、好友列表或好友水族箱启动。
