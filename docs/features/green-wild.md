# 绿野寻仙踪 (`GreenWildTask` / `GreenWildDailyTask`)

## 独立任务

`GreenWildTask` 从主鱼缸进入绿野寻仙踪，打开任务后一键领取，再返回鱼缸。

1. 在 `[140, 278, 49, 50]` 识别并点击 `绿野寻仙踪_入口.png`；
2. 在 `[41, 345, 68, 59]` 识别并点击 `绿野寻仙踪_任务.png`；
3. 在 `[1089, 579, 107, 39]` OCR 点击“一键领取”；关键词用稳定子串 `键领取`，兼容漏掉“一”字；
4. 在 `[1180, 50, 61, 55]` 识别并点击 `绿野寻仙踪_返回.png`；
5. 匹配 `主界面特征.png` 确认回到主鱼缸。

未识别到领取按钮时不报错、不停止，直接点击右上角返回并确认主鱼缸。

任一扇门未通过则安全停止，不使用固定坐标猜测。

## 日常收尾子任务

`绿野寻仙踪日常` 勾选后按固定顺序执行：

1. 复用 `OpenShellTask` 开贝壳 1 次（`CheckOpenShellLoopReco` 默认 `target_count=1`）；
2. 开贝壳确认回到主鱼缸后，若本日常子任务仍待买鱼，进入商店买一条贝币鱼：
   - `[1171, 497, 44, 37]` 识别并点击 `买鱼入口.png`；
   - `[411, 119, 116, 34]` OCR 点击“贝币鱼儿”；
   - 在 `[93, 295, 208, 180]` 范围内点击鱼卡；
   - `[856, 521, 81, 38]` OCR 点击“购买”；
   - `[360, 543, 181, 39]` OCR 点击“继续购物”；
   - `[57, 28, 82, 45]` OCR 点击“返回”，连续两次；
   - 确认主鱼缸后结束并回到日常收尾调度。

独立开贝壳任务在回到鱼缸后走 `OpenShellStandaloneComplete`，不会进入买鱼。
