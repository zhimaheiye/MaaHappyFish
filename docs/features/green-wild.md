# 绿野寻仙踪 (`GreenWildTask` / `GreenWildDailyTask`)

## 独立任务

`GreenWildTask` 从主鱼缸进入绿野寻仙踪，打开任务后一键领取，再返回鱼缸。已在任务页时直接领取，不要求再点入口。

1. 在放宽后的入口 ROI 识别并点击 `绿野寻仙踪_入口.png`，点击后等待约 5 秒让活动页加载完再识别；
2. 在左侧任务栏识别并点击 `绿野寻仙踪_任务.png`，模板未命中则 OCR `^任务$`；
3. 在 `[1050, 540, 200, 90]` OCR 点击“一键领取”；关键词用稳定子串 `键领取`，兼容漏掉“一”字；
4. 在右上角识别并点击 `绿野寻仙踪_返回.png`（绿色 X）；
5. 匹配 `主界面特征.png` 确认回到主鱼缸。

任务页已打开时优先领取。未识别到领取按钮时不报错、不停止，直接点击右上角返回。入口/任务/返回模板不再使用与切图等大的紧框，避免 1 像素偏移就判门禁失败。

任一扇门未通过则安全停止，不使用固定坐标猜测。

## 日常收尾子任务

`绿野寻仙踪日常` 勾选后按固定顺序执行：

1. 复用 `OpenShellTask` 开贝壳 1 次（`CheckOpenShellLoopReco` 默认 `target_count=1`）。开贝壳完成后的退出由 open_shell 模块自身按页面分流（2026-09-18 修复：第一次返回可能只到贝壳分类页，需第二次返回后才回主鱼缸），本子任务无需处理中间页；
2. 开贝壳确认回到主鱼缸后，若本日常子任务仍待买鱼，进入商店买一条贝币鱼：
   - `[1171, 497, 44, 37]` 识别并点击 `买鱼入口.png`；
   - `[411, 119, 116, 34]` OCR 点击“贝币鱼儿”；
   - 在 `[93, 295, 208, 180]` 范围内点击鱼卡；
   - `[856, 521, 81, 38]` OCR 点击“购买”；
   - `[360, 543, 181, 39]` OCR 点击“继续购物”；
   - `[57, 28, 82, 45]` OCR 点击“返回”，连续两次；
   - 确认主鱼缸后结束并回到日常收尾调度。

独立开贝壳任务在回到鱼缸后走 `OpenShellStandaloneComplete`，不会进入买鱼。
