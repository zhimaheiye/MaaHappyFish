## V1 Scope

- 独立任务，不接 DailyRoutine。配置方式分为“逐只设置”和“统一设置”。
- 逐只设置：1~8 号分别选择鱼食（黄袋/超级鱼食/青花瓷袋）、玩耍（摸头/篮球/唱歌/跳过）和牛奶（粉色/黄色/蓝莓味）。默认鱼食为超级鱼食、牛奶为蓝莓味，玩耍仍默认全部跳过。
- 统一设置：分别选择一档鱼食、一种玩耍方式和一档牛奶，并覆盖本轮全部 1~8 号宝宝。统一玩法默认“全部跳过”，避免首次打开配置时意外消耗资源。
- 跳过仍是整只宝宝的总开关：该宝宝本轮不会喂食、玩耍或喂奶。睡眠中的宝宝也会自动跳过。
- 一轮按鱼食偏好分组喂食 → 按玩耍偏好分组 → 按牛奶偏好分组。每只参与宝宝的既有资源门禁仍按 15 鱼食、100 爱心核对；不自动购买、补爱心或点击付费“一键孵化”。
- V1 不自动读成长日记、识别品种或推断偏好。宝宝更换后需手工核对成长日记并更新编号。

## Start Contract

1. `鱼宝配置方式` 控制 MFA 只展示一组配置：
   - 逐只设置显示 24 个子选项（8 只 × 鱼食/玩耍/牛奶）；
   - 统一设置显示 3 个汇总子选项。
2. `FishBabyFoodPreference1..8`、`FishBabyPreference1..8`、`FishBabyMilkPreference1..8` 分别写入三类逐只偏好；`FishBabyUniformFood/Play/Milk` 在选择统一模式时覆盖对应类别。`PER_BABY` 表示不覆盖。每次任务启动全部重置，避免上次模式残留。
3. 有效玩耍配置全为 SKIP 时立即结束，不进入游戏页面。统一玩法选具体项目时会让 1~8 号全部参与，随后仍按真实睡眠状态跳过不可操作宝宝。
4. 支持从主鱼缸、鱼宝主页、孵化大类层、任一子项层和“请选择鱼宝宝”层启动。主鱼缸先匹配 `主界面特征.png`，再按珊瑚 `(905,593)` → 首个气泡 `(787,477)` 盲连击；只用活动暖色指纹确认是否进入，未知页 StopTask，禁止 Android BACK。
5. 鱼宝主页须同时命中暖色指纹和“开始孵化”才进入。子项层或已选子项层只在 OCR 命中已知提示后点击金色返回箭头 `(851,635)`，直到“请选择孵化方式”。
6. 红旗编号会在浮具间换位。运行时使用 `assets/resource/image/fish_baby/number_1.png` 至 `number_8.png` 定位当帧编号，再按最近的固定浮具槽位映射宝宝点击中心；缺任一已配置编号或槽位冲突立即停止。
7. 当帧先读取每只目标的状态：冷却倒计时表示睡眠并跳过；红心数 `0/2/4` 分别表示从喂食/玩耍/喂奶恢复。其他红心数视为未知状态并停止。
8. 每个偏好批次严格验证“大类提示 → 子项提示 → 请选择鱼宝宝 → 每只绿勾 → 资源计数足够且与人数一致 → 执行按钮属于当前类别 → 执行后回到大类层”。已实机确认的超级鱼食、摸摸头、玩球、唱歌、蓝莓味牛奶继续核对精确按钮文字；新增两档鱼食和两档牛奶因来源只记录颜色/外观，按钮仅在执行按钮 ROI 内核对“鱼粮/鱼食”或“牛奶”类别词。最终必须逐只 OCR 到冷却倒计时才算本轮完成。
9. 完成或全部目标正在睡眠后，先从孵化层返回活动主页，再由主页 X 返回主鱼缸；最终以 `主界面特征.png` 确认。
