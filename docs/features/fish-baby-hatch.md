## V1 Scope

- 独立任务及日常收尾可选“鱼宝乐园”子任务共用 `FishBabyTask`。任务设置分为喂食、玩耍、喂奶三个独立配置组，三组同时存在，不再使用互斥的总模式开关；日常勾选后展开同样的三组配置，默认不勾选。
- 每一组都可单独选择“逐只设置”或“一键统一”：逐只设置会展开该列的 1~8 号选项；统一选项只覆盖该类别，不影响另外两列。
- 喂食列支持黄袋、超级鱼食、青花瓷袋，默认“一键全部超级鱼食”；玩耍列支持摸头、篮球、唱歌、跳过，默认“逐只设置”，每只玩法默认跳过；喂奶列支持粉色、黄色、蓝莓味，默认“一键全部蓝莓味牛奶”。
- 因三列互相独立，常用配置可保持“全部超级鱼食 + 逐只玩法 + 全部蓝莓味牛奶”；也可把任一列切换为逐只配置。
- 跳过仍是整只宝宝的总开关：该宝宝本轮不会喂食、玩耍或喂奶。睡眠中的宝宝也会自动跳过。
- 一轮按鱼食偏好分组喂食 → 按玩耍偏好分组 → 按牛奶偏好分组。每只参与宝宝的既有资源门禁仍按 15 鱼食、100 爱心核对；不自动购买、补爱心或点击付费“一键孵化”。
- V1 不自动读成长日记、识别品种或推断偏好。宝宝更换后需手工核对成长日记并更新编号。

### 当前流程

1. 任务顶层按顺序提供 `鱼宝喂食设置`、`鱼宝玩耍设置`、`鱼宝喂奶设置` 三组。每组的“逐只设置”只展开本类别 1~8 号选项；该组的一键选项直接覆盖本类别全部宝宝。
2. `FishBabyFoodPreference1..8`、`FishBabyPreference1..8`、`FishBabyMilkPreference1..8` 分别写入三类逐只偏好；`FishBabyUniformFood/Play/Milk` 分别接收三个配置组的一键覆盖。`PER_BABY` 表示该类别沿用逐只值。每次任务启动全部重置，避免上次选择残留。
3. 有效玩耍配置全为 SKIP 时不操作任何宝宝：独立运行立即结束；日常模式经 `FishBabySkipAllVerifyTank` 确认主鱼缸后记为 `SKIPPED` 并继续队列。此跳过分支故意不支持从鱼宝中间页启动日常，未确认主鱼缸则安全停止，避免队列跨层点击。一键统一玩法选具体项目时会让 1~8 号全部参与，随后仍按真实睡眠状态跳过不可操作宝宝。
4. 支持从主鱼缸、鱼宝主页、孵化大类层、任一子项层和“请选择鱼宝宝”层启动。主鱼缸先匹配 `主界面特征.png`，再按珊瑚 `(905,593)` → 首个气泡 `(787,477)` 盲连击；用活动暖色指纹与后续 OCR 门禁确认是否进入，未知页安全失败，禁止 Android BACK。
5. 鱼宝主页须同时命中暖色指纹和“开始孵化”才进入。子项层或已选子项层只在 OCR 命中已知提示后点击金色返回箭头 `(851,635)`，直到“请选择孵化方式”。
6. 红旗编号会在浮具间换位。运行时使用 `assets/resource/image/fish_baby/number_1.png` 至 `number_8.png` 定位当帧编号，再按最近的固定浮具槽位映射宝宝点击中心；缺任一已配置编号或槽位冲突立即停止。
7. 当帧先读取每只目标的状态：冷却倒计时表示睡眠并跳过；红心数 `0/2/4` 分别表示从喂食/玩耍/喂奶恢复。其他红心数视为未知状态并停止。
8. 每个偏好批次严格验证“大类提示 → 子项提示 → 请选择鱼宝宝 → 每只绿勾 → 资源计数足够且与人数一致 → 执行按钮属于当前类别 → 执行后确认大类层或牛奶睡眠主页”。已实机确认的超级鱼食、摸摸头、玩球、唱歌、蓝莓味牛奶继续核对精确按钮文字；新增两档鱼食和两档牛奶因来源只记录颜色/外观，按钮仅在执行按钮 ROI 内核对“鱼粮/鱼食”或“牛奶”类别词。最终必须逐只 OCR 到冷却倒计时才算本轮完成。
9. 完成或全部目标正在睡眠后，按真实页面选择退出：仍在大类层则先返回主页；牛奶后已自动回主页则直接走主页 X。主页关闭必须同时命中暖色指纹与“开始孵化”，最终以 `主界面特征.png` 确认。`FishBabyVerifyTankAfterRound` 通过 `DailyRoutineSubtaskDoneAction` 在当前步骤为 `FISH_BABY` 时仅推进一次，再由日常/独立双出口分流；未知页面或养成失败由 `FailTaskAction` 返回 `FAILED`，不写入完成。
10. 日常顺序为购买鱼食（若勾选）→ 鱼宝乐园 → 乐队鱼 Pass 2（若勾选）→ 两项末尾奖励领取。喂食类别沿用配置，不会因为前一步购买了廉价鱼食就自动改成黄袋或跳过资源门禁。挂机历史 `all_enabled` 不自动启用此新子任务，须显式开启。
