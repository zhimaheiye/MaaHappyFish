## 原 Start Contract 与退出（当前暂停）

`DailyRoutineStepActivityEnergy` 仅在日常队列当前步骤为 `ACTIVITY_ENERGY` 时触发。按当前画面从深到浅识别：酿月食香页 → 精彩活动列表 → 主鱼缸。主鱼缸先确认 `主界面特征.png`，再识别并点击精彩活动入口；列表先确认左上返回模板，再核对并点击第一张卡片；活动页先确认专属关闭模板，再检查可选「收下」。未知页面、模板缺失或点击后未出现预期页面都 StopTask。

处理结束后只点击酿月食香专属关闭按钮，确认回到活动列表，再点击列表的旧返回按钮；`主界面特征.png` 确认回缸后才提交一次日常子任务完成。该任务不由全局“意外活动页”处理器中途接管；日常调度器对其他子任务仍保留该全局处理。
