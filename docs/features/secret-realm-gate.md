# 秘境之门自动化 (docs/features/secret-realm-gate.md)

**最后更新**: 2026-09-19

## 功能定位

开心水族箱"秘境之门"送鱼任务自动化（`SecretRealmGateTask`）。既支持独立运行，也作为日常收尾可选子任务（队列顺序在绿野寻仙踪日常之后）。进入秘境之门主页后循环识别右侧任务列表中的「送出」按钮并逐个处理，全部处理完后返回主鱼缸。

## Start Contract（两态步骤可恢复）

1. **已在秘境之门主页**（最深）：ROI `[464,0,354,127]` 识别 `秘境之门_识别.png`（顶部标题）确认，直接进入送出识别循环；
2. **在主鱼缸**：先点击右下角宝箱（`右下角_宝箱.png`，ROI `[1120,562,141,141]`，与魔力召唤/宝石融合同款菜单入口）→ ROI `[573,621,58,40]` 识别 `秘境之门_入口.png` 点击 → `秘境之门_识别.png` 确认主页；
3. 未知页面：`SecretRealmGateAbort`（StopTask）安全停止。
4. **不支持在弹窗中启动**（分支一送出弹窗 / 分支二确认删除弹窗均为瞬态，无法安全恢复身份）——恢复路由遇弹窗会安全停止，用户关闭弹窗后再启动即可。

## 主循环：送出识别

- 在 `[930,149,149,522]` 任务列表列范围 OCR `^送出$`，**点击 OCR 命中框中心（文字本身）**；「送出」可能出现在三个固定位置 `[961,259,83,29]`、`[962,442,84,28]`、`[961,626,83,28]`（对应三张任务卡片），无需逐位置建节点，大 ROI 识别 + 命中框点击天然覆盖；
- 点击后按页面状态分流（下方分支）；每个分支结束统一回流 `SecretRealmGateSendRouter` 继续识别下一个「送出」；
- 列内不再有「送出」→ 进入退出链。

## 分支一：正常送出（用户实测已录入）

1. OCR `[531,44,211,35]` 弹窗标题 **分词兼容** `选择|送出的鱼`（兼容"选择你""要送出的"等被拆分的词组）；
2. 门禁：`秘境之门_确定送出条件.png` `[179,229,107,37]`（鱼只已选中状态）识别成功才允许继续；未识别到时**安全停止**（该子分支待实机补充，见下）；
3. OCR 点击弹窗底部「送出」`[886,646,68,28]`；
4. OCR 点击「领取」`[605,583,68,34]` → 等待 5 秒（post_delay 5000）→ 同一位置 OCR 点击「确定」；
5. 本次送出结束，回流主循环。

## 分支二：没有这种鱼（用户实测已录入）

1. OCR `[684,333,255,139]` **分词兼容** `没有这种鱼|您没有`；
2. 删除对应卡片的垃圾桶图标——**必须与刚点击的「送出」同卡片**，采用相对位置偏移（用户实测：送出按钮 `[980,441,51,29]` 时垃圾桶在 `[1239,330,15,17]`，即中心偏移 **(+241, -117)**）。实现为 `SecretRealmGateClickDeleteAction`：从 runtime 状态读取本次送出 OCR 框 → 按偏移推算期望位置 → 在 ±40px 容差窗口内用 `秘境之门_删除.png` 模板确认（order_by Distance）→ 点击实际命中位置；未命中则报错并安全失败，**拒绝盲点其它卡片的垃圾桶**；
3. 点击确认删除对号 `秘境之门_确认删除.png` `[804,462,44,44]` → 分支结束回流主循环。

## ⚠️ 未录入分支（重要备忘）

用户明确说明：**至少还有一个分支尚未录入**（实测条件所限未能触发）。当前实现中，点击「送出」后若既未命中分支一弹窗、也未命中分支二提示，将走 `SecretRealmGateAbort` 安全停止——不会盲点。待用户下次实机遇到新分支时截图补充，再扩展 `SecretRealmGateClickSend.next` 的候选。

其它待补充观察项：
- 分支一中"确定送出条件"不成立（鱼只未选中/需先点选卡片）时的处理方式；
- 分支二"您没有这种鱼"提示是否自动消失（当前实现 post_delay 2000 等待后直接处理垃圾桶，若提示为需要手动关闭的弹窗需补关闭步骤）。

## 退出链

任务列表无「送出」后：OCR `[0,0,200,120]` `^返回$` 点击左上角返回 → `主界面特征.png` 确认主鱼缸 → `SecretRealmGateDoneAction` 标记完成 → 标准双出口（`DailyRoutineReturnIfActive` / `DailyRoutineStandaloneDone`）。

## 日常收尾接入

- `DailyRoutineEnableSecretRealmGate`（默认 enabled: false）；
- `DailyRoutineStepSecretRealmGate`（expected_step `SECRET_REALM_GATE`）；
- 调度队列顺序：`GREEN_WILD_DAILY` 之后、`GOLDEN_DOLPHIN` 之前；
- interface「日常收尾任务」多选框新增「秘境之门」（默认不勾选）。
