## 页面与启动契约

- 支持在秘境之门主页直接启动，先匹配顶部 `秘境之门_识别.png`；在主鱼缸启动时先确认主缸并打开底栏，再匹配紫色秘境入口；未知页面走 `SecretRealmGateAbort`（StopTask）。不支持在中途弹窗启动。
- 右侧订单区 `[930,149,149,522]` 只接受 OCR 完整文字 `^送出$`，从上到下逐单处理；同样绿色的“钞票 xN”是付费锁定按钮，绝不点击，也不等倒计时。
- 点击订单前再次截图，验证主页和同一行“送出”。记录本次 OCR 框作为删除身份。点击后每 500 ms 读新帧，最多 9 秒，等待“选择您要送出的鱼”或“您没有这种鱼”。单帧 miss 不跳过；持续不明时停止任务。

## 数量语义与三种结果

订单的“需要：A/B”是**拥有该鱼的总数 A / 需要送出的鱼苗数 B**，总数可能包含成年鱼。即使 `72/12`，也不能凭 `72 >= 12` 决定送出。唯一送鱼判据是选择面板底部“已经选中 N/M 条鱼”：面板默认勾选幼鱼，N 是实际选中的鱼苗数，M 是需求数。

| 当前结果 | 门禁与动作 |
| --- | --- |
| 有足够鱼苗，如 `1/1`、`6/6` | 选择面板标题和 N/M 均读到且 `N >= M`，再识别底部 `^送出$` 并点击实际 OCR 框。等待 `^领取$`，点击后继续逐帧等 `^确定$`（随机奖励动画可能持续 3–6 秒），点击实际 OCR 框，确认回主页后重新扫描订单。 |
| 有鱼但鱼苗不足，如 `4/7` | 选择面板确认且 `N < M`，点击其右上 X `(1158,82)`；确认弹窗已关且回主页，然后用原订单“送出”框推算同卡垃圾桶，命中模板才点击；确认删除对号模板命中才点击，回主页后重扫。 |
| 没有这种鱼 | 验证“您没有这种鱼”弹窗，点击窗外空白 `(300,300)` 关闭（此窗无 X）；确认回主页后按同卡垃圾桶和确认删除模板完成删单，再重扫。 |

删除相对坐标采用原“送出”框中心 `(+241,-117)`，只在目标 ±40px 窗口匹配 `秘境之门_删除.png`，并复核返回框确在此窗口内。其它槽即使匹配分数更高也不点击。删除确认使用 `秘境之门_确认删除.png` 的真实命中框。

## 终止与保护

- 每次送出或删单后，游戏可能把该槽补为倒计时 + “钞票 xN”的锁定单。只扫描当场可用的 `^送出$`；稳定 2.5 秒没有该文字后还必须通过秘境主页门禁，才可点击左上“返回”并确认主鱼缸。
- 弹窗/计数/按钮/同卡垃圾桶/删除确认/领奖确认/回主页任一门禁在限时内未通过，均走 `SecretRealmGateAbort`，不盲点、不跳行、不触碰“购买”或“钞票 xN”。
- 日常收尾内部路由与独立入口代码保留，便于日后实机取证；当前 UI 不提供开启途径。以后得到用户允许并完成 MFA 实机复测后，再考虑恢复独立任务入口。
