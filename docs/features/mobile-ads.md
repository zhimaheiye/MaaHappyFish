# 看广告（手机与模拟器）

## 模块定位与环境约束
- **模块定位**：专为 Android 真实手机环境（开心水族箱手机客户端）打造的无人干预连续观看广告与转盘领奖自动化功能。
- **环境要求**：Android 真机物理横屏（20:9，如 2400×1080），MaaFramework 内部按短边锚定 720p 自动等比缩放为 **1600×720** 处理。触控下发时按 1.5 倍缩放比精确映射至物理屏幕。
- **物理隔离原则**：独立流水线 `assets/resource/pipeline/features/mobile_ads.json` 与独立资产目录 `assets/resource/image/mobile_ads/`，严格禁止与桌面端/MuMu 1280×720 资产交叉混用。

### MuMu 模拟器 (`EmulatorAdTask`)

- **模块定位**：为 MuMu 模拟器的标准 `1280×720` 截图坐标系提供独立看广告入口；不复用手机端 `1600×720` 的模板或 ROI。
- **用户素材**：`看视频赚大奖.png`、`看广告页面_关闭.png`、`停止按钮_可点击.png`、`停止按钮_不可点击.png`、`下一段视频_对号.png`。
- **识别约定**：五张模板均在完整 `[0,0,1280,720]` 画面中定位并点击实际命中位置，不设置固定点击坐标；可点击/不可点击两张停止按钮使用 `0.8` 阈值，离线互相匹配分数约 `0.586`。
- **代码状态**：已完成代码接入与静态验证，本次未运行模拟器；真实模板命中率与广告提供方页面变化由用户后续 MFA 测试确认。

## 状态机架构与流转设计

### 1. 深度优先步骤可恢复路由 (Deepest-First State-Resumable Router)
任务启动或中途恢复时，按真实页面状态由深至浅自动接管：
```text
MobileAdTask -> MobileAdRouter
                  ├─ [终态/弹窗] 识别到“恭喜获得奖励/要继续观看下一段视频” -> 结算或继续分流
                  ├─ [转盘状态] 识别到转盘“停止”按钮 -> 进入转盘停止控制
                  ├─ [Endcard] 识别到右上角独立关闭 X -> 安全关闭广告
                  ├─ [广告播放] 处于非 MainActivity 或检测到播放中胶囊 -> 安全等待播放完毕
                  └─ [大厅入口] 位于广告中心大厅 -> 识别并点击【看视频赚大奖】
```

模拟器端保持相同业务语义，但用独立状态机处理其页面：

```text
EmulatorAdTask -> EmulatorAdRouter
  -> 奖励弹窗：记录完成轮数 -> 达上限则识别关闭；否则点击下一段视频对号
  -> 停止按钮可点击：点击停止 -> 等待奖励或“再来一次”
  -> 停止按钮不可点击：不点击，短暂等待后重新识别
  -> 广告关闭按钮：点击并回到转盘状态路由
  -> 看视频赚大奖：点击入口 -> 标记新一轮 -> 最长等待 80 秒关闭按钮
  -> 启动时处于广告中：未知页面不盲点，直接等待用户提供的关闭模板；超时安全停止
```

### 2. Endcard 与播放中防误触门禁 (Anti-Premature-Click Protection)
- **视觉冲突特征**：广告播放期间右上角存在倒计时胶囊 `[ 🔊 | ✕ ]`（中心 x 约 1507）；广告播放完毕后的 Endcard 结束页存在独立白粗圆 `✕`（中心 x 约 1547，y 约 51）。
- **门禁控制**：Endcard 模板匹配 ROI 严格收紧在 `[1515, 20, 75, 70]`。实测播放中胶囊在该区域匹配度 `<= 0.1666`，真实 Endcard 匹配度 `>= 0.999`，判定阈值设定为 `0.80`，从视觉源头彻底杜绝播放中误触。

### 3. 转盘自适应多重停止机制 (Adaptive Wheel Deceleration)
- 转盘开始旋转后，大黄色按键文案由“旋转”切换为“停止”（OCR ROI `[980, 480, 160, 140]`）。
- 点击“停止”后转盘减速结算；若命中“再来一次”格子，转盘会无缝重新启动旋转。
- **自适应状态机**：只要检测到“停止”即下发点击（安全上限 5 次），直到“恭喜你获得如下奖励”弹窗出现时自然跃迁，完美化解单次旋转与多次重转。

### 4. 奖励弹窗双出口与无人干预连续流转
- **业务语义明确**：游戏内广告观看无次数上限，界面 `(n/10)` 仅作为周期性观察标记，**绝对不作为终止判断**。
- **绿色对号快捷继续**：弹窗右下角检测到绿色对号 `✔`（ROI `[930, 455, 120, 130]`），只要未达到本次任务配置的目标轮数（`completed_cycles < max_cycles`），自动点击拉起下一条广告（实测拉起耗时 ~3.07s）。
- **红色叉号安全退出**：达到用户设定的运行轮数（如完成 3 轮）时，识别点击红色 `✖`（ROI `[840, 455, 100, 110]`），安全返回大厅优雅终止任务。严禁无模板盲点保底。

## 任务选项与安全限制
在 `interface.json` 中提供共享的连续观看轮数选项，手机与模拟器任务分别覆盖自己的计数节点：
- `3 轮(默认测试)`：单次运行观看 3 条广告并转盘结算，适合日常快速取证与验收。
- `5 轮`：连续观看 5 条广告并转盘结算。
- `10 轮`：连续观看 10 条广告并转盘结算。

## 超时分层架构 (Tiered Timeouts)
- **广告启动验证**：~10~15 秒（检测广告 activity 或播放胶囊）；
- **广告播放与 Endcard 等待**：~80 秒（节点 `timeout: 80000`，稳定容纳 30~60 秒视频播放）；
- **广告关闭与返回**：~20 秒（`MobileAdEndcard` 与 `MobileAdPostReturnRouter`，`timeout: 20000`）；
- **转盘停止响应**：~15 秒（`MobileAdWheelStop`，`timeout: 15000`）；
- **弹窗识别**：~10 秒（`MobileAdVerifyRewardPopup`，`timeout: 10000`）。
