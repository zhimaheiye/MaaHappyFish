# 金海豚小游戏 (GoldenDolphinTask)

## 功能概述
金海豚小游戏是游乐园内的敏捷类限时采集活动。玩家通过游乐园面板进入，接取下落的金币并尽可能拾取高价值的经验五角星（XP）。

---

## 核心机制与重大发现 (Critical Architectural Discovery)

> [!IMPORTANT]
> **进入小游戏后不是立即开始正式计时，存在隐藏启动状态！**

### 隐藏启动状态机：`GoldenDolphinWaitingStart`
```
进入小游戏
   │
   ▼
[GoldenDolphinWaitingStart] (持续点击识别到的贝币)
   │
   ▼ (首次识别到经验星)
正式开始计时 (30s 倒计时开始跑动)
   │
   ├─ [0s ~ 30s]：纯金币雨阶段
   └─ [30s ~ 48s]：XP 经验五角星雨阶段
```

### 未激活启动状态的表现：
1. 画面固定停留在初始状态（顶部显示静态 `30.0 s` 与 `0 X Combo`）；
2. 仅在水体中出现并漂浮初始金币；
3. **绝对不出现 XP/爱心等进阶奖励**；
4. 若此时执行 XP 检测算法，将永远处于等待状态（0 检出）；
5. 实测单击一枚贝币不足以稳定启动；玩家连续点击多次后才开始加载。因此 Agent 必须在经验星出现前持续识别并点击**实际贝币**，点击水体空白位置不能可靠启动。

### 当前最小状态机（2026-09-08）：

1. 在游戏水体区域内匹配用户提供的 `金海豚_贝币.png`；
2. 每帧优先识别经验星；尚未出现经验星时，持续点击模板命中的贝币中心，不使用固定坐标兜底；
3. `金海豚_经验星1.png`、`金海豚_经验星2.png` 任一模板命中都视为经验星并点击；首次命中后永久停止点击贝币，切换到高频经验收集；
4. 每帧最多批量点击 4 个经验目标，结算模板每 5 帧检查一次，并响应任务停止请求。

## 视觉识别算法 (Method E: 经验星检测方案)

基础检测方案曾通过 Phase 1.5 全量 175 帧离线 Benchmark；当前在此基础上扩展为双模板识别，双模板的实机吞吐仍待下次体力可用时验证：

```
[截屏图像 720×1280]
       │
       ▼
1. 【全屏 HSV 颜色掩膜粗筛】（完整 `1280×720`，不限制经验星出现坐标）
   - H ∈ [15, 35], S ∈ [65, 255], V ∈ [110, 255]
       │
       ▼
2. 【几何形态学过滤】
   - 宽高比保持近似方形，滤除扁平金币
   - 面积和边框尺寸范围根据经验星1/2模板尺寸动态扩展，并保留原检测范围
       │
       ▼
3. 【双模板局部微补丁确认】
   - 每个候选分别按经验星1、经验星2的实际模板尺寸取样匹配
   - 任一模板达到阈值即命中；同一候选即使两个模板都命中也只点击一次
   - matchTemplate 阈值 ≥ 0.45
   - 输出中心点击坐标 (cx, cy)
```

### 运动学特性与点击范围
- **运动规律**：垂直单向匀速下落，横坐标 $x$ 恒定不变（漂移 $\le 2\text{px}$）；
- **下落速度**：匀速 $65.5\text{ px/s}$；
- **存活时间**：单颗星存活 $9.5 \sim 9.8\text{ 秒}$，提供 $6 \sim 8\text{ 秒}$ 充裕点击窗口；
- **点击范围**：进入金海豚小游戏后整个画面均属于小游戏，经验星在完整 `1280×720` 画面内识别和点击，不设置横向或纵向 ROI。

## 安全导航与状态门禁规范 (Safe Navigation & State Verification)

1. **统一模板路径解析**：
   - 动态判定有效资源目录（支持嵌入式 Release、开发环境及 `client_avalonia` NTFS Junction）；
   - 杜绝模板静默为 `None`，关键模板缺失时抛出 `ERROR` 并强行中断。
2. **状态前置门禁链条**：
   - **Deepest-First 识别**：启动时优先识别游乐园面板是否已打开（金海豚图标 match $\ge 0.70$）；
   - **主鱼缸安全点击**：未在面板时，识别 `游乐园入口.png`（match $\ge 0.70$），点击入口后轮询等待面板展开；
   - **绝对杜绝盲目兜底**：彻底废除 `(674, 468)` 盲目点击；当面板未打开或未识别到金海豚图标时，坚决终止，禁止在主鱼缸误戳鱼群。
