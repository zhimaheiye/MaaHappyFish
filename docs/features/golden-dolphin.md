# 金海豚小游戏 (GoldenDolphinTask)

## 功能概述
金海豚小游戏是游乐园内的敏捷类限时采集活动。玩家通过游乐园面板进入，接取下落的金币并尽可能拾取高价值的经验五角星（XP）。

---

## 核心机制与重大发现 (Critical Architectural Discovery)

> [!IMPORTANT]
> **进入小游戏后不是立即开始正式计时，存在隐藏启动状态！**

### 隐藏启动状态机：`GoldenDolphinWaitingStart`
```
进入小游戏
   │
   ▼
[GoldenDolphinWaitingStart] (等待玩家首次交互/点击)
   │
   ▼ (玩家完成启动点击)
正式开始计时 (30s 倒计时开始跑动)
   │
   ├─ [0s ~ 30s]：纯金币雨阶段
   └─ [30s ~ 48s]：XP 经验五角星雨阶段
```

### 未激活启动状态的表现：
1. 画面固定停留在初始状态（顶部显示静态 `30.0 s` 与 `0 X Combo`）；
2. 仅在水体中出现并漂浮初始金币；
3. **绝对不出现 XP/爱心等进阶奖励**；
4. 若此时执行 XP 检测算法，将永远处于等待状态（0 检出）；
5. 必须先由 Agent 或玩家完成**首次启动交互/点击**，游戏才会真正启动倒计时与经验星掉落流程。

### 后续复工待确认事项：
1. **任意点击是否可以启动**：点击水体空白处是否能触发计时开始；
2. **是否必须点击金币**：是否必须首发点击/捕获一枚金币才激活；
3. **启动后多久进入 XP 阶段**：从首次有效激活到经验星进入黄金点击区的时间延迟。

## 视觉识别算法 (Method E: 经验星检测方案)

经 Phase 1.5 全量 175 帧离线 Benchmark 评估，确认采用三级漏斗式复合检测架构（纯 CPU 耗时仅 33ms，支持 30 FPS 实时处理）：

```
[截屏图像 720×1280]
       │
       ▼
1. 【HSV 颜色掩膜粗筛】 (H ∈ [15, 35], S ∈ [65, 255], V ∈ [110, 255])
       │
       ▼
2. 【几何形态学刚性过滤】 (100% 滤除扁平金币)
   - 面积 Area ∈ [950, 3300]
   - 宽高比 w/h ∈ [0.80, 1.30] (金币为 2.5)
   - 边框尺寸 w ∈ [48, 78], h ∈ [44, 78]
       │
       ▼
3. 【局部微补丁模板确认】 (仅匹配 65×62 小候选区)
   - matchTemplate 阈值 ≥ 0.50
   - 输出中心点击坐标 (cx, cy)
```

### 运动学特性与黄金点击带
- **运动规律**：垂直单向匀速下落，横坐标 $x$ 恒定不变（漂移 $\le 2\text{px}$）；
- **下落速度**：匀速 $65.5\text{ px/s}$；
- **存活时间**：单颗星存活 $9.5 \sim 9.8\text{ 秒}$，提供 $6 \sim 8\text{ 秒}$ 充裕点击窗口；
- **推荐黄金点击带**：$y \in [180, 540]$（避开顶栏 UI 与底层海豚遮挡）。

## 安全导航与状态门禁规范 (Safe Navigation & State Verification)

1. **统一模板路径解析**：
   - 动态判定有效资源目录（支持嵌入式 Release、开发环境及 `client_avalonia` NTFS Junction）；
   - 杜绝模板静默为 `None`，关键模板缺失时抛出 `ERROR` 并强行中断。
2. **状态前置门禁链条**：
   - **Deepest-First 识别**：启动时优先识别游乐园面板是否已打开（金海豚图标 match $\ge 0.70$）；
   - **主鱼缸安全点击**：未在面板时，识别 `游乐园入口.png`（match $\ge 0.70$），点击入口后轮询等待面板展开；
   - **绝对杜绝盲目兜底**：彻底废除 `(674, 468)` 盲目点击；当面板未打开或未识别到金海豚图标时，坚决终止，禁止在主鱼缸误戳鱼群。
