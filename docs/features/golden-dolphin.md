# 金海豚小游戏 (GoldenDolphinTask)

## 功能概述
金海豚小游戏是游乐园内的敏捷类限时采集活动。任务默认连续执行最多 3 局，全屏识别经验星、爱心、宝石与贝币。用户可以选择任一类别作为最高优先级；该类别未命中时，会在同一帧立即处理其他已识别奖励，不设置额外等待。

---

## 核心机制与重大发现 (Critical Architectural Discovery)

> [!IMPORTANT]
> **进入小游戏后不是立即开始正式计时，存在隐藏启动状态！**

### 隐藏启动状态机：`GoldenDolphinWaitingStart`
```
进入小游戏
   │
   ▼
[奖励选择循环] (所选优先级未命中时同帧兜底到实际贝币)
   │
   ▼ (连续点击实际贝币后奖励雨开始)
正式开始计时 (30s 倒计时开始跑动)
   │
   ├─ [0s ~ 30s]：纯金币雨阶段
   └─ [30s ~ 48s]：XP 经验五角星雨阶段
```

### 未激活启动状态的表现：
1. 画面固定停留在初始状态（顶部显示静态 `30.0 s` 与 `0 X Combo`）；
2. 仅在水体中出现并漂浮初始金币；
3. **不出现经验星、爱心、宝石等进阶奖励**；
4. 其余类别识别为 0 时，奖励选择器会自然兜底到实际贝币；
5. 实测单击一枚贝币不足以稳定启动；玩家连续点击多次后才开始加载。因此 Agent 必须持续识别并点击**实际贝币**，点击水体空白位置不能可靠启动。

### 当前状态机（2026-09-15）：

1. 爱心、4 种宝石、3 种贝币和 2 种经验星全部在完整 `1280×720` 画面识别；
2. 独立任务和日常收尾均可选择经验星、爱心、宝石或贝币作为最高优先级，默认经验星；
3. 每帧先识别所选最高优先级；若未命中，立即用同一张截图按 `经验星 → 爱心 → 宝石 → 贝币` 的稳定顺序检查其余类别，不等待 1 秒；
4. 首选类别存在时只点击首选；首选不存在时立刻点击当前可识别的其他奖励。首次出现经验星后也不会永久禁点贝币；
5. 每帧最多批量点击 4 个当前优先级目标，结算模板每 5 帧检查一次，并响应任务停止请求；
6. 每局结算等待 `金海豚_结束取消.png` 真正出现，点击模板命中位置，并以 `主界面特征.png` 确认返回主鱼缸后重新导航；完成第 3 局后结束。若任意一次进入时识别到机会已用完，同样必须完成物理归位，再记为 `NO_STAMINA` 并进入下一个日常任务。

## 视觉识别算法

基础检测方案曾通过 Phase 1.5 全量 175 帧离线 Benchmark；当前在此基础上扩展为双模板识别，双模板的实机吞吐仍待下次体力可用时验证：

```
[截屏图像 720×1280]
       │
       ▼
1. 【全屏 HSV 颜色掩膜粗筛】（完整 `1280×720`，不限制经验星出现坐标）
   - H ∈ [15, 35], S ∈ [65, 255], V ∈ [110, 255]
       │
       ▼
2. 【几何形态学过滤】
   - 宽高比保持近似方形，滤除扁平金币
   - 面积和边框尺寸范围根据经验星1/2模板尺寸动态扩展，并保留原检测范围
       │
       ▼
3. 【双模板局部微补丁确认】
   - 每个候选分别按经验星1、经验星2的实际模板尺寸取样匹配
   - 任一模板达到阈值即命中；同一候选即使两个模板都命中也只点击一次
   - matchTemplate 阈值 ≥ 0.45
   - 输出中心点击坐标 (cx, cy)
```

### 其他奖励模板识别

- 爱心、宝石和贝币使用用户截图模板执行 `TM_CCOEFF_NORMED` 全屏匹配，阈值 `0.70`；
- 同一类别的编号图片是不同视觉变体，任一变体命中都归入同一类别；
- 多模板在同一目标周围产生的重叠结果会合并，只保留最高置信度命中；
- 识别不到任何模板时保持等待，不点击固定坐标。

### 运动学特性与点击范围
- **运动规律**：垂直单向匀速下落，横坐标 $x$ 恒定不变（漂移 $\le 2\text{px}$）；
- **下落速度**：匀速 $65.5\text{ px/s}$；
- **存活时间**：单颗星存活 $9.5 \sim 9.8\text{ 秒}$，提供 $6 \sim 8\text{ 秒}$ 充裕点击窗口；
- **点击范围**：进入金海豚小游戏后整个画面均属于小游戏，四类奖励都在完整 `1280×720` 画面内识别和点击，不设置横向或纵向 ROI。
- **优先级**：用户所选类别始终排第一；其余类别按 `经验星 → 爱心 → 宝石 → 贝币` 的顺序补齐。首选未命中时在同一帧立即兜底，不使用时间阈值。

## 安全导航与状态门禁规范 (Safe Navigation & State Verification)

1. **统一模板路径解析**：
   - 动态判定有效资源目录（支持嵌入式 Release、开发环境及 `client_avalonia` NTFS Junction）；
   - 杜绝模板静默为 `None`，关键模板缺失时抛出 `ERROR` 并强行中断。
2. **状态前置门禁链条**：
   - **Deepest-First 识别**：启动时优先识别游乐园面板是否已打开（金海豚图标 match $\ge 0.70$）；
   - **主鱼缸安全点击**：未在面板时，识别 `游乐园入口.png`（match $\ge 0.70$），点击入口后轮询等待面板展开；
   - **绝对杜绝盲目兜底**：彻底废除 `(674, 468)` 盲目点击；当面板未打开或未识别到金海豚图标时，坚决终止，禁止在主鱼缸误戳鱼群。
3. **结算归位门禁（2026-09-15 修复）**：
   - 现场日志显示小游戏循环超时结束时结算页尚未出现，旧 `GoldenDolphinExitAction` 随即执行固定坐标点击、未验证主鱼缸便记录第 1 局完成；后续导航又把过渡弹窗当作次数耗尽，最终在仍处于金海豚结算页时推进到摇一摇，导致 `ShakeGameNavigation` 失败；
   - 现改为轮询等待结算取消模板，点击实际命中中心；若落在游乐园面板，仅在面板模板命中后收起；最终必须以 `主界面特征.png`（阈值 0.70）确认归位，失败则在金海豚节点安全终止，绝不推进后续任务；
   - 弹窗起点必须由 `金海豚_确定按钮.png` 命中确认，绿色 HSV 仅用于按钮中心定位，不能再凭任意绿色区域单独判定弹窗。
