# 公主任务 (`PrincessTask`)

## 功能概述

公主任务是独立的每日领奖流程。任务从主鱼缸识别入口进入，确认公主任务页面后，把右侧奖励列 `[1028, 290, 62, 288]` 分成上、中、下三格依次点击；每格点击命中框并处理领取成功、失败或「积分不足」提示。三格全部领取后页面会切换到“公主宝箱任务”，任务会继续检查额外宝箱，再退出回鱼缸。

`PrincessTask` 每次进入时由 `ResetPrincessClaimHitsAction` 清除三格的 MaaFramework `max_hit` 计数。`max_hit: 1` 仅限制**本次进入**时每格最多点击一次；日常收尾中途和末尾两次调用同一入口时，末尾会按当前画面重新检查三格。重置失败则安全停止，不跳过图像识别直接点击。

## 启动契约

`PrincessStartRouter` 使用最深阶段优先：

1. 已在宝箱奖励“你真棒”：点击 OCR 命中按钮，随后退出任务页；
2. 已在普通奖励“开心收下”：点击 OCR 命中按钮，回普通页面继续扫描；
3. 已在领取失败弹窗：点击 `公主任务_领取失败.png` 的真实命中框，回普通页面继续扫描；
4. 已在“公主宝箱任务”页面：在 `[494,158,292,141]` OCR 识别“公主宝箱任务”，直接检查额外宝箱；
5. 已在普通公主日记页面：以 `公主任务_识别.png` 确认后直接开始检查奖励；
6. 画面上已有「交付任务」按钮：在日记模板之后、OCR「日记」之前，于 `[260,250,720,430]` 精确识别并点击一次「交付任务」，然后走既有退出。顶部条 `[512,62,253,143]` 里未选中的「日记」和悬赏页可以同时出现，所以不能先认「日记」；
7. 日记模板未中、且没有「交付任务」：同一顶部条 OCR「日记」，走原来的三格领取，不点「交付任务」；
8. 仍未分开时：顶部 OCR「悬赏|赏金」后再点「交付任务」；
9. 在主鱼缸：在 `[29,264,50,37]` 识别并点击 `公主任务_入口.png`，随后按上述页面门禁判断当前阶段；
10. 以上状态均未识别：进入 `PrincessAbort`，独立任务安全结束，日常收尾跳过本步骤。

「交付任务」按钮 ROI 没有实机截图，按 1280×720 写在管线里：按钮在标题下方、日记礼盒列左侧。日记模板、日记 OCR 和领取后的回页检查都不包含这个按钮。

“积分不足/无法领取”OCR 只负责说明语义，关闭动作仍必须由现有 `公主任务_领取失败.png` 模板命中后执行；不把任意含该文字的弹窗假定为同一关闭按钮。

## 领取方式与结果分流

整列一次搜索会反复命中最上面、看起来最像模板的礼盒。现将 `[1028,290,62,288]` 均分成三格，每格最多点一次：

- 上格 `[1028,290,62,96]`
- 中格 `[1028,386,62,96]`
- 下格 `[1028,482,62,96]`

点击命中框，不设置固定 `target`。某格没有礼盒或已经点过，就试下一格。命中后进入并列结果分支：

- 成功：在 `[586,518,102,32]` OCR 精确识别并点击“开心收下”；
- 失败：在 `[760,380,180,180]` 识别并点击 `公主任务_领取失败.png`；
- 「积分不足 / 无法领取」：关闭提示后继续下一格。

成功或失败处理后回到公主任务页，再点还没点过的格子。三格都结束后退出。

## 公主宝箱任务分支

三格全部领取后，普通页面门禁消失，`PrincessPageAfterClaim` 转入以下分支：

1. 在 `[494,158,292,141]` OCR 识别“公主宝箱任务”，确认当前页面；
2. 在 `[376,501,40,40]` 匹配并点击 `公主宝箱任务_领取.png`，点击实际命中位置，不设置固定坐标；
3. 若模板未命中，表示额外任务尚未完成，直接识别右上角退出按钮并返回鱼缸，属于正常结束，不报错；
4. 若模板命中并开启奖励，在 `[596,517,86,31]` OCR 精确识别并点击“你真棒”，随后点击右上角退出并确认回到鱼缸。

## 退出与完成

奖励列不再命中后，在 `[1068,121,37,39]` 识别并点击 `公主任务_退出.png`；随后匹配 `主界面特征.png` 确认返回主鱼缸。退出模板或主鱼缸门禁未通过时安全停止。
