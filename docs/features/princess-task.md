# 公主任务 (`PrincessTask`)

## 功能概述

公主任务是独立的每日领奖流程。任务从主鱼缸识别入口进入，确认公主任务页面后，把右侧奖励列 `[1028, 290, 62, 288]` 分成上、中、下三格依次点击；每格点击命中框并处理领取成功、失败或「积分不足」提示。三格全部领取后页面会切换到“公主宝箱任务”，任务会继续检查额外宝箱，再退出回鱼缸。

## 启动契约

`PrincessStartRouter` 使用最深阶段优先：

1. 已在“公主宝箱任务”页面：在 `[494,158,292,141]` OCR 识别“公主宝箱任务”，直接检查额外宝箱；
2. 已在普通公主任务页面：以 `公主任务_识别.png` 确认后直接开始检查奖励；
3. 在主鱼缸：在 `[29,264,50,37]` 识别并点击 `公主任务_入口.png`，随后按上述两个页面门禁判断当前阶段；
4. 三种状态均未识别：进入 `PrincessAbort` 安全停止，不点击固定坐标。

## 领取方式与结果分流

整列一次搜索会反复命中最上面、看起来最像模板的礼盒。现将 `[1028,290,62,288]` 均分成三格，每格最多点一次：

- 上格 `[1028,290,62,96]`
- 中格 `[1028,386,62,96]`
- 下格 `[1028,482,62,96]`

点击命中框，不设置固定 `target`。某格没有礼盒或已经点过，就试下一格。命中后进入并列结果分支：

- 成功：在 `[586,518,102,32]` OCR 精确识别并点击“开心收下”；
- 失败：在 `[760,380,180,180]` 识别并点击 `公主任务_领取失败.png`；
- 「积分不足 / 无法领取」：关闭提示后继续下一格。

成功或失败处理后回到公主任务页，再点还没点过的格子。三格都结束后退出。

## 公主宝箱任务分支

三格全部领取后，普通页面门禁消失，`PrincessPageAfterClaim` 转入以下分支：

1. 在 `[494,158,292,141]` OCR 识别“公主宝箱任务”，确认当前页面；
2. 在 `[376,501,40,40]` 匹配并点击 `公主宝箱任务_领取.png`，点击实际命中位置，不设置固定坐标；
3. 若模板未命中，表示额外任务尚未完成，直接识别右上角退出按钮并返回鱼缸，属于正常结束，不报错；
4. 若模板命中并开启奖励，在 `[596,517,86,31]` OCR 精确识别并点击“你真棒”，随后点击右上角退出并确认回到鱼缸。

## 退出与完成

奖励列不再命中后，在 `[1068,121,37,39]` 识别并点击 `公主任务_退出.png`；随后匹配 `主界面特征.png` 确认返回主鱼缸。退出模板或主鱼缸门禁未通过时安全停止。
