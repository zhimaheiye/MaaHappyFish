# 公主任务 (`PrincessTask`)

## 功能概述

公主任务是独立的每日领奖流程。任务从主鱼缸识别入口进入，确认公主任务页面后，按下、中、上的顺序检查三个奖励位置；每次点击后分别处理领取成功或领取失败弹窗，最后点击页面右上角退出并确认返回主鱼缸。

## 启动契约

`PrincessStartRouter` 使用最深阶段优先：

1. 已在公主任务页面：以 `公主任务_识别.png` 确认后直接开始检查奖励；
2. 在主鱼缸：在 `[29,264,50,37]` 识别并点击 `公主任务_入口.png`，随后必须通过页面门禁；
3. 两种状态均未识别：进入 `PrincessAbort` 安全停止，不点击固定坐标。

## 领取顺序与结果分流

三个 `公主任务_领取奖励.png` 识别区域依次为：

1. 下方：`[1041,533,36,42]`；
2. 中间：`[1044,432,36,42]`；
3. 上方：`[1045,316,36,42]`。

用户给出的原始高度为 `39`；因 `公主任务_领取奖励.png` 实际尺寸为 `34×42`，Pipeline 将三个搜索框的高度最小扩大为 `42`，否则模板无法放入 ROI。三个位置的 `x/y/宽度` 均保持不变。

每个位置只在模板命中后点击；未命中代表该位置当前无可领取奖励，直接继续下一位置。点击后进入并列结果分支：

- 成功：在 `[586,518,102,32]` OCR 精确识别并点击“开心收下”；
- 失败：在 `[804,461,46,41]` 识别并点击 `公主任务_领取失败.png`；
- 两种结果均未出现：安全停止，不猜测弹窗状态。

成功或失败按钮点击后，均需重新在 `[512,62,253,143]` 匹配 `公主任务_识别.png`，确认已经回到正确页面，才能处理下一位置。

## 退出与完成

三个位置处理完毕后，在 `[1068,121,37,39]` 识别并点击 `公主任务_退出.png`；随后匹配 `主界面特征.png` 确认返回主鱼缸。退出模板或主鱼缸门禁未通过时安全停止。

## 资产与验证状态

使用用户提供的五张模板：`公主任务_入口.png`、`公主任务_识别.png`、`公主任务_领取奖励.png`、`公主任务_领取失败.png`、`公主任务_退出.png`。本轮采用用户截图模式，代码只验证文件存在、Pipeline 拓扑、ROI、正则、资源加载和界面配置；模板实际命中率及完整流程由用户在 MFA 中测试。
