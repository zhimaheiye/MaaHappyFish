# 海獭摸宝自动化 (docs/features/sea-otter-gem.md)

## 功能定位
开心水族箱海獭寻宝特定宝石自动化助手（SeaOtterGemTask）。针对用户在海獭寻宝中选定特定宝石并进入寻宝好友列表/鱼缸的场景，自动化在相邻好友之间往复切换、高效摸取目标宝石，并在好友体力耗尽后自动向后滑动窗口，直到到达陌生人/好友列表边界安全退出。

## 核心设计与业务机制
1. 对称双摸与离开即刷新：窗口内两端好友（i, i+1）每次进入都点击海獭摸宝，离开并重新进入后目标宝石立即刷新。
2. 海獭精准安全触控：左下角安全坐标 (85, 565)，远离鱼群游动区域，匹配海獭模板 assets/resource/image/海獭_摸宝.png。
3. 极简响应式状态机：仅以真实 UI 出现「刷新体力」为耗尽依据，零历史数据负担；窗口自然向后推进。
4. 步骤可恢复与安全边界：支持从鱼缸或好友列表断点启动，遇到陌生人推荐页安全收敛退出，全程 0 货币消耗。
